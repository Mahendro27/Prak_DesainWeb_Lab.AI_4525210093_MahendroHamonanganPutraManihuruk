# **Struktur Dasar Dokumen** 

- <!doctype html>: Mendeklarasikan bahwa dokumen ini ditulis menggunakan standar HTML5. 

- <html long="id">: Tag pembuka dari keseluruhan halaman web. Terdapat sedikit kesalahan penulisan atribut, yang seharusnya adalah lang="id" untuk mengidentifikasi bahwa bahasa utama dokumen adalah bahasa Indonesia. 

- <head>: Bagian yang memuat metadata halaman, termasuk pengaturan karakter standar (charset="UTF-8"), penyesuaian skala layar untuk perangkat seluler (viewport), dan penamaan judul tab peramban (<title>Profil Mahasiswa</title>). 

- <body>: Bagian utama yang membungkus seluruh konten visual yang akan dilihat oleh pengguna di layar. 

# **Hierarki Judul (Heading)** 

- Tag <h1>, <h2>, dan <h3> digunakan untuk menyusun struktur judul halaman dari yang paling besar ke kecil. <h1> digunakan untuk judul utama "Profil Mahasiswa", <h2> untuk nama, dan <h3> untuk sub-bagian seperti "Informasi singkat" dan "Karakter Khusus". 

# **Paragraf dan Pemformatan Teks** 

- <p>: Tag paragraf untuk mengelompokkan teks biasa. 

- <strong>: Membuat teks menjadi tebal untuk memberikan penekanan makna penting pada kata "Desain web". 

- <em>: Membuat teks menjadi miring (italic) untuk penekanan pada kata "UI design". 

- <br />: _Line break_ atau pemutus baris, digunakan untuk menurunkan teks ke baris berikutnya tanpa membuat paragraf baru, seperti pada detail Program Studi, Semester, dan Kota. 

- <b>: Membuat teks menjadi tebal secara visual pada kalimat "Target: Belajar:". 

# **Entitas Karakter (HTML Entities)** 

- &lt; dan &gt;: Digunakan untuk memunculkan simbol kurang dari (<) dan lebih dari (>). Hal ini memungkinkan teks seperti <p> dan <h1> dapat dibaca di layar sebagai tulisan biasa, alih-alih dianggap sebagai kode oleh peramban. 

- &copy;: Kode khusus untuk menampilkan simbol hak cipta (©) pada kalimat bagian bawah halaman.
