**PERTEMUAN 8:** 

**1.Radio Button (type="radio")** : Digunakan untuk memilih salah satu opsi jadwal kelas. Atribut name="jadwal" disamakan agar berfungsi sebagai satu grup. 

**2.Checkbox (type="checkbox")** : Digunakan untuk fasilitas tambahan (opsional) dan persetujuan komitmen yang bersifat wajib. 

**3.Select Box (<select>)** : Menampilkan opsi program kursus dalam bentuk _drop-down_ . 

**4.Textarea (<textarea>)** : Mengambil masukan teks multi-baris untuk kolom motivasi bergabung. 

**5.Upload Pembayaran (type="file")** : Memungkinkan pengguna memilih dokumen lokal. Wajib menggunakan atribut form enctype="multipart/form-data". 

**6. 3 Jenis Button** : 

- <button type="submit">: Mengirim data form. 

- <button type="reset">: Menghapus seluruh isian form kembali ke state awal. 

- <button type="button">: Menjalankan fungsi JavaScript (dalam hal ini _alert_ bantuan). 

# **7. 4 Aturan Validasi Bawaan :** 

- required: Field wajib diisi sebelum submit. 

- minlength: Membatasi jumlah minimal karakter (contoh pada nama dan textarea motivasi). 

- pattern: Menguji format menggunakan _Regular Expression_ (RegEx) pada nomor telepon. 

- accept: Membatasi tipe file saat jendela unggah terbuka (.jpg,.png,.pdf).
