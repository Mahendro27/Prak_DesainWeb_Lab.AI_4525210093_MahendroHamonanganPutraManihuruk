Penjelasan Style

1. Penggunaan 4 Format Warna yang Berbeda

Pada modifikasi kode, telah diterapkan 4 format warna CSS yang berbeda untuk memenuhi spesifikasi tugas praktikum:

  • HEX Code: #8B0000

    Digunakan pada warna teks judul utama, garis tepi (border), dan elemen aksen dekoratif.

  • HSL (Hue, Saturation, Lightness): hsl(0, 100%, 30%) & hsl(0, 80%, 90%)

    Digunakan pada garis pembatas <hr> dan latar belakang paragraf penekanan (highlight).

  • RGBA (Red, Green, Blue, Alpha): rgba(0, 0, 0, 0.3)

    Digunakan pada properti Box-Shadow foto profil untuk memberikan efek bayangan yang transparan dan halus.

  • RGB (Red, Green, Blue): rgb(245, 245, 220) & rgb(50, 50, 50)

    Digunakan untuk warna latar belakang utama halaman (beige) dan warna teks sub-judul.

2. Properti CSS Inline yang Digunakan (> 10 Properti)

Untuk menata tata letak dan visual halaman tanpa file CSS terpisah, digunakan 13 properti CSS inline berikut:

  1. font-family:Mengatur jenis huruf
  2. background-color:Mengatur warna latar belakan
  3. margin:Mengatur jarak luar
  4. padding:Mengatur jarak antar baris teks
  5. line-height:Mengatur warna teks
  6. color:Mengatur ukuran teks
  7. font-size:Mengatur ketebalan teks
  8. font-weight:Mengatur perataan teks
  9. text-align:Mengubah bentuk teks menjadi huruf kapital
  10. text-transform:Membuat sudut melengkung pada gambar/kotak
  11. border:Mengatur garis tepi
