## 1. Penggunaan 4 Format Warna yang Berbeda

- Format 1 (HEX): #8B0000 (Digunakan pada warna teks judul, garis pembatas gambar, dan aksen border).

- Format 2 (HSL): hsl(0, 100%, 30%) dan hsl(0, 80%, 90%) (Digunakan pada garis <hr/> dan latar belakang kotak catatan bawah).

- Format 3 (RGBA): rgba(0, 0, 0, 0.3) (Digunakan untuk efek bayangan/box-shadow pada foto profil agar tampak lebih hidup).

- Format 4 (RGB): rgb(245, 245, 220) dan rgb(50, 50, 50) (Digunakan untuk warna latar belakang halaman utama dan warna teks sub-judul).

## 2. Properti CSS Inline yang Digunakan (> 10 Properti)

Kode di atas menggunakan lebih dari 10 properti CSS inline yang tersebar di berbagai elemen, di antaranya:

- 1. font-family (Mengatur jenis huruf)

- 2. background-color (Mengatur warna latar belakang)

- 3. margin (Mengatur jarak luar)

- 4. line-height (Mengatur jarak antar baris teks)

- 5. color (Mengatur warna teks)

- 6. font-size (Mengatur ukuran teks)

- 7. font-weight (Mengatur ketebalan teks)

- 8. text-align (Mengatur perataan teks)

- 9. text-transform (Mengubah bentuk teks menjadi huruf kapital)

- 10. border-radius (Membuat sudut melengkung pada gambar/kotak)

- 11. border / border-bottom / border-left (Mengatur garis tepi)

- 12. box-shadow (Memberikan efek bayangan)

- 13. padding (Mengatur jarak dalam elemen)
